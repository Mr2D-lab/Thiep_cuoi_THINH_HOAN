================================================================================
🌸 HƯỚNG DẪN ĐƯA THIỆP CƯỚI LÊN WEB (VERCEL / GITHUB) & QUẢN TRỊ ADMIN
================================================================================

Thư mục Web_Deploy đã được tích hợp đầy đủ:
✓ Định tuyến Vercel thông minh (vercel.json) — truy cập /tên_người_nhận không bao giờ bị 404.
✓ Chế độ Nhà phát triển #admin chỉnh sửa trực quan WYSIWYG trên web.
✓ Công cụ Tạo Thiệp Gửi Từng Khách Mời với 2 ô họ tên riêng biệt, vai vế cố định, toggle Cô dâu/Chú rể.
✓ Đồng bộ vĩnh viễn danh sách khách (guests.json) lên GitHub API không lo mất dữ liệu.
✓ Nút [🔄 Khôi Phục] (Revert) lấy lại dữ liệu gốc từ GitHub nếu lỡ tay gõ nhầm.
✓ Bẫy chống bot tự động (Honeypot 1 giờ) và chống spam F5.

--------------------------------------------------------------------------------
PHẦN 1: ĐƯA LÊN VERCEL (KHUYÊN DÙNG ĐỂ CHẠY LINK /tên_khách HOÀN HẢO NHẤT)
--------------------------------------------------------------------------------
1. Truy cập https://vercel.com và đăng nhập (bằng tài khoản GitHub hoặc Google).
2. Kéo thả trực tiếp cả thư mục Web_Deploy này vào trang Vercel (hoặc kết nối với GitHub repo).
3. Vercel sẽ tự động đọc file `vercel.json` để kích hoạt chế độ URL Rewrites.
4. Sau vài giây, bạn sẽ có đường link web chính thức dạng:
   https://thiep-cuoi-hoan-thinh.vercel.app

--------------------------------------------------------------------------------
PHẦN 2: CÁCH TRUY CẬP CHẾ ĐỘ NHÀ PHÁT TRIỂN & BẢO MẬT
--------------------------------------------------------------------------------
1. Truy cập vào web với đuôi `#admin`:
   Ví dụ: https://thiep-cuoi-hoan-thinh.vercel.app/#admin
2. Nhập mật khẩu quản trị (Mặc định: hoanthinh2026) -> Bấm "Đăng Nhập".
3. Thanh công cụ nổi (Floating Bar) xuất hiện ở đáy màn hình:
   - [💌 Tạo Thiệp Khách]: Mở trình tạo thiệp & danh sách khách mời.
   - [💾 Lưu Thay Đổi]: Gửi dữ liệu mới sửa lên GitHub.
   - [🔄 Khôi Phục]: Khôi phục lại dữ liệu gốc gần nhất nếu lỡ tay xóa nhầm.
   - [⚙️ GitHub]: Điền Token & Tên Repo để lưu dữ liệu vĩnh viễn.
   - [📥 Tải File]: Tải file config.js dự phòng về máy tính.
   - [👁️ Thoát]: Trở về giao diện người xem thông thường.

--------------------------------------------------------------------------------
PHẦN 3: CÁCH TẠO THIỆP GỬI RIÊNG CHO TỪNG KHÁCH MỜI
--------------------------------------------------------------------------------
1. Bấm nút [💌 Tạo Thiệp Khách] trên thanh công cụ.
2. Form gồm 5 bước cực kỳ tiện lợi:
   - Mục 1: Chọn Danh xưng / Vai vế (Chị, Anh, Em, Bạn, Bác, Chú, Cô...) — Chỉ cho phép chọn.
   - Mục 2: Nhập Họ và tên đầy đủ (ví dụ: Nguyễn Thị Lan) — Dùng cho danh sách & tự điền form RSVP.
   - Mục 3: Tên hiển thị trên thiệp (Hệ thống tự gợi ý: "Chị Lan", bạn có thể sửa lại nếu muốn).
   - Mục 4: Chọn khách của ai (Click chọn [👰 Bạn của Cô dâu] hoặc [🤵 Bạn của Chú rể]).
   - Mục 5: Đường link cá nhân hóa (Tự gợi ý /Thiep_cuoi_gui_chi_lan, bạn có thể tự sửa).
3. Bấm nút [✅ Xác Nhận & Tạo Thiệp]:
   - Hệ thống hiển thị ngay đường link kèm nút [📋 Sao Chép Link] và [👁️ Mở Xem Thử].
   - Danh sách khách được lưu đồng bộ lên GitHub (guests.json) và bộ nhớ máy.
4. Sang tab "Danh Sách Đã Tạo" để xem tổng số khách, sao chép link bất kỳ, hoặc xóa khách bằng nút [🗑️ Xóa] riêng của từng người.

--------------------------------------------------------------------------------
PHẦN 4: TRẢI NGHIỆM CỦA KHÁCH MỜI KHI NHẬN LINK CÁ NHÂN HÓA
--------------------------------------------------------------------------------
Khi khách mời (ví dụ: Chị Lan) mở link https://.../Thiep_cuoi_gui_chi_lan:
- Phong bì mở đầu trang trọng hiện: "Trân trọng kính mời: Chị Lan".
- Thiệp chính hiển thị: "Kính mời Chị Lan cùng gia đình tới dự lễ cưới...".
- Phần phản hồi (RSVP): Ô họ tên tự động điền sẵn "Nguyễn Thị Lan" và tự động chọn sẵn "Bạn của Cô dâu".
Khách mời chỉ cần bấm chọn tham dự là xong, vô cùng chu đáo và sang trọng!
