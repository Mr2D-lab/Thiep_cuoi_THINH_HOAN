Công Cụ Tạo Link Ngụy Trang Google Sheet

Chuyển đổi mật khẩu thành đường link Google Apps Script dự phòng hoàn toàn hợp lệ để lưu vào config.js.

Đường link Google Sheet ngụy trang tương ứng:
Đang tạo mã...
Dòng cấu hình sẵn sàng dán vào config.js:
Đang tạo...

📖 Hướng dẫn cách đổi mật khẩu:

  1. Gõ mật khẩu mới bạn muốn vào ô trên (ví dụ: @motdenchin).
  2. Bấm nút "Sao Chép Cả Dòng config.js".
  3. Mở file config.js bằng VS Code hoặc Notepad.
  4. Tìm đến dòng "backupGoogleSheetUrl": ... và dán đè dòng vừa copy vào.
  5. Lưu file và đẩy lên GitHub. Khi đăng nhập #admin trên web, bạn gõ đúng mật khẩu mới là vào được!
Đã sao chép vào bộ nhớ tạm!
